workspace

A macOS CLI for managing tmuxinator-based development workspaces in iTerm2 — launch, focus, kill and relaunch projects with automatic window positioning.

Requirements

  • macOS (uses AppleScript and Accessibility APIs)
  • Ruby 3.x
  • iTerm2
  • tmux and tmuxinator
  • window-tool and git

A headless launch needs only Ruby, tmux, tmuxinator and git — no macOS, iTerm2 or window-tool.

brew install tmux tmuxinator gh
brew install zdennis/bin/window-tool

Install

Clone the repo and put bin/ on your PATH:

git clone https://github.com/zdennis/workspace.git ~/source/opensource/workspace
export PATH="$HOME/source/opensource/workspace/bin:$PATH"

Add the export line to your ~/.zshrc to keep it across shells.

Set up

Create the config directories and install the agent hooks:

workspace init

Then verify everything is in place:

workspace doctor

doctor checks for the required tools and prints install instructions for anything missing.

First run

The first AppleScript call asks whether your terminal may control iTerm2 — click OK. Also grant your terminal (and window-tool) access under System Settings → Privacy & Security → Accessibility. Without it, workspace launch and focus can't position windows.

Then add a project and launch it:

cd ~/source/my-project
workspace add
workspace launch my-project

Full documentation in the repo README and docs/.
