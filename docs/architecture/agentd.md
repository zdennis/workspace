# Agent daemon

The per-workspace agent daemon: its socket and router, the recovery desk, restart and prompt-queue desks, handoff and pipeline traffic. Full per-file detail, moved verbatim from `.claude/CLAUDE.md`; the one-line index there links here.

- `lib/workspace/agent_restart.rb` — The daemon's `restart_agent` worker: waits for a quiet pane, types `/clear` under the delivery lock, confirms it, types the prompt. A moving screen is accepted only on proof the main turn is over (`turn_over:`, `screen_ready:`, held 5s) and then warns that background work may be lost; a Claude Code pane is re-checked under the lock (a draft is `input_not_empty`, a started turn `turn_started`); `run_id:` stops it with `run_unbound` once the pane is no longer bound to that run; it takes a `PaneFactory` (`panes:`): the plain screen through `#for`, and the pane list once per typing through `#call`, so a gone pane or an unlisted session both read as `pane_gone` Its `restarted` reply carries `cleared_at` (ISO 8601, the wall clock once the new conversation is confirmed).
- `lib/workspace/agentd_parts.rb` — `AgentdParts`, the frozen Struct of the parts the agent daemon builds per workspace (`hook_event_log`, `monitor`, `restart_runner`, `restart_desk`, `plan_progress_watcher`, `spine_owner_report`, `spine_watcher`, `status_desk`, `queue_desk`, `recovery_desk`, `handoff_watcher`, `pipeline_desk`, `work_queue_desk`, `hook_fanout`), as `Workspace.build_agentd_parts`' builder returns them (spec `spec/unit/workspace/build_agentd_parts_spec.rb`); flat until T50 renames it `Agentd::Parts`
- `lib/workspace/commands/agent.rb` — The agent daemon's command object, built by `Workspace.build_agent_daemon`, which injects every object it uses (it calls `.new` only on `Mutex`); `parts:` is the per-workspace builder from `Workspace.build_agentd_parts`, called in `#call` for the pipeline desk alone (`pipeline_only: true`, after the socket is claimed, where it recovers the in-flight items and registers) and again for the rest (`pipeline_desk:`), and at once for the desk alone by `#prepare(name)` (the workspace served before `#call`); `#call` starts the parts in order (monitor, plan watcher, spine watcher with its owner report, desks, `on_scan`); `command` and `inject` go to the `pipeline_desk` (`command` given the injected `claude_pane:` lookup, with its fall back to pane `0.1` here), as do `#report_progress` and `#fail_pipeline`, and the socket watcher's re-registration (`PipelineDesk#re_register`); `#handle(message, client = nil)` is public (the socket protocol's one entry, which specs call; it goes to an `AgentdRouter` over this class's table of one handler per message type, built by the injected `router_for:` for the workspace served); the socket is the injected `socket_server:` (an `AgentdSocketServer`), whose TERM/INT handler it installs, whose watcher ticks the workflow nudger (which also starts `workflow sweep` for the workspace about every 5 minutes while a run is going) and re-registers; router examples over `#handle` in `spec/unit/workspace/commands/agent_spec.rb`; a `session_event` goes to the parts' `hook_fanout` (nothing before `#call` builds the parts), and the monitor's `on_scan` to its `#scan_desks`; a `restart_agent` goes to the parts' `restart_desk`, and before `#call` builds the parts is refused through `AgentdRestartDesk.refusal_before_start`; it holds no context reader It keeps `parts.hook_event_log` and passes it to `WorkflowNudger#tick` as `hook_log:` from the socket watcher's `on_tick`. A `sessions` message with `rescan: true` first runs `SessionMonitor#rescan_unclassified`.
- `lib/workspace/agentd_restart_desk.rb` — `AgentdRestartDesk#handle(message, client)`: the daemon's side of `restart_agent`: checks the message (`missing_prompt`, `context_unavailable` with no context reader, `bad_timeout` past `MAX_TIMEOUT`, which `Commands::Agent::MAX_RESTART_TIMEOUT` names), resolves the pane through `pane_details:` (`missing_pane`, `bad_pane`, `wrong_session`, `no_such_pane`), the monitor's kind (`not_an_agent` after one rescan, `unsupported_agent`), `pipeline_ref:` (`pane_in_pipeline` unless `force`), the context reading (`context_unknown`), the registry claim (`restart_in_progress`), then replies `started` (unless `wait`) and starts the `RestartRunner` on a worker thread; built per workspace by `Workspace.build_agentd_parts` as `AgentdParts#restart_desk`; spec `spec/unit/workspace/agentd_restart_desk_spec.rb` over `RecordingRestartMonitor`, `RecordingContextReader`, `RecordingRestartRegistry` and `RecordingRestartRunner` (`spec/support/fakes/agentd_parts.rb`, each in `fake_contract_spec`); flat until T50
- `lib/workspace/hook_fanout.rb` — `HookFanout`, the agent daemon's fan-out of one workspace's hook events: `#session_event(message)` hands each to the handoff watcher (a failure there logged), the monitor, the hook event log, the workflow nudger and the spine owner report (those two for the main agent only; the report on its own thread through `spawn:`), then the queue desk and the recovery desk, in that order; a main agent's `stop` also calls `WorkQueueDesk#turn_ended` (`work_queue_desk:`, nil calls none) through `WorkflowNudger#turn_ended`'s `on_exit:` once the advance it woke has exited, or at once when the nudger is nil or woke no run; it keeps when each pane's main-agent turn began (`user_prompt`, cleared at `session_start`/`session_end`) and passes it with a `stop` to `WorkflowNudger#turn_ended`; `#scan_desks` is the monitor's after-scan call (each desk's `scan`, then the work queue desk's, one that raises logged and the next still run); built by `Workspace.build_agentd_parts` as `AgentdParts#hook_fanout`; spec `spec/unit/workspace/hook_fanout_spec.rb` over `RecordingHookMonitor`, `RecordingHookLog`, `RecordingHandoffWatcher`, `RecordingNudger`, `RecordingOwnerReport`, `RecordingHookDesk` and `RecordingWorkQueueDesk` (`spec/support/fakes/agentd_parts.rb`, each in `fake_contract_spec`); flat until T50 A `stop` also passes the fan-out's own `hook_log` to `WorkflowNudger#turn_ended` as `hook_log:`, so the nudger's decision lines share the log's one `boot_id` and `seq`. A `stop` also passes the hook's `transcript_path` to `WorkflowNudger#turn_ended`.
- `lib/workspace/agentd_router.rb` — `AgentdRouter`, the agent daemon's table from an `AgentProtocol` type to its handler (`workspace:`, `handlers:`, `logger:`): `#handle(message, client)` logs the message, hands `coordinator_restart` (`UNADDRESSED`) to its handler whatever workspace it names, refuses another workspace (`WorkspaceName.same?`) with `wrong_workspace`, then calls the type's handler with the message and client (it answers through `#reply` and returns `:handed_off` when a worker owns the client) or answers `unknown_type`; `#reply(client, payload)` writes one JSON line, a hung-up client logged; `Workspace.build_agent_daemon` builds it per workspace served, through the `router_for:` lambda it gives `Commands::Agent`; spec `spec/unit/workspace/agentd_router_spec.rb`; flat until T50
- `lib/workspace/agentd_socket_server.rb` — `AgentdSocketServer`, the agent daemon's Unix socket (`bind:`, `poll_interval:`, `tick_passes:`): `#claim(name, path, force:)` (a stale socket removed, a running daemon refused or, forced, stopped through `lsof` and SIGTERM), `#listen`, `#serve(router)` (one JSON line per connection to `AgentdRouter#handle`, `malformed_message` and `internal_error` answered through `#reply`, the connection closed unless handed off, a rebound server taken over), `#watch(path, needs_registration:, on_tick:, re_register:)` (the watcher thread: rebinds a socket whose file is gone and re-registers until that succeeds), `#shut_down!`, `#wake`, `#install_signal_handlers(on_signal:)` (traps TERM and INT through `signal_trapper:`, moved from `Commands::Agent`: `on_signal`, then `#close` on a new thread, since `IO#close` raises `ThreadError` in trap context; binds through its own `UNIXServer`, which that spec replaces), `#close`, `#close_and_remove`; `Workspace.build_agent_daemon` builds it and gives it to `Commands::Agent`; spec `spec/unit/workspace/agentd_socket_server_spec.rb` over `RecordingRouter` (`spec/support/fakes/agentd_parts.rb`, in `fake_contract_spec`); flat until T50
- `lib/workspace/pipeline_desk.rb` — `PipelineDesk`, the agent daemon's pipeline and work-coordinator traffic for one workspace: `#command(message, claude_pane:)` types a coordinator command into the first pipeline stage with its sentinel instruction (or the Claude pane with no pipeline), `#inject` takes a steer (urgent: C-c and typed now; else queued for the next stage; `no_active_pipeline`, `stale_token`, `no_next_stage`), each stage watched by a `SentinelPoller` and handed on through a hand-off file, `#recover_in_flight`, `#register` (under a fresh `epoch_generator:` epoch unless given one)/`#send_registration`/`#deregister`, `#re_register` (at the daemon's socket under a fresh `epoch_generator:` epoch, after a coordinator restart or a socket rebind; warns once while refused or unreachable, then says once that it re-registered), `#coordinator_restarting`, `#pipeline_ref_on`, `#report_progress`, `#fail_pipeline`, `#stop_watches`; every report stamped, retried `REPORT_ATTEMPTS` times, buffered (`MAX_PENDING_REPORTS`) and replayed after a re-registration; one state lock, taken inside the daemon's delivery lock; `stage_marks:` gives a started stage its token and deadline; built by `Workspace.build_agentd_parts` as `AgentdParts#pipeline_desk`; spec `spec/unit/workspace/pipeline_desk_spec.rb` over `RecordingPipelineConfig`, `RecordingPipelineState`, `RecordingCoordinatorClient` and `RecordingSentinelPoller` (`spec/support/fakes/agentd_parts.rb`, each in `fake_contract_spec`) and `FakeTmux`; flat until T50
- `lib/workspace/agent_message_client.rb` — `AgentMessageClient#call(project, message)`: one message to a workspace's agent daemon over its Unix socket and its one-line reply parsed, no time limit; `no_daemon`, `connection_failed`, `unreadable_reply`; `agent-run command`/`inject`, `agent run PROMPT` and `pipeline start`/`advance` send through it; built in `build_cli`
- `lib/workspace/work_coordinator_client.rb` — JSONL client for work-coordinator sockets
- `lib/workspace/pipeline_config.rb` — (`pipeline` is deprecated in favor of `workflow`) Reads per-project pipeline stage config from `~/.config/workspace/projects/<name>.yml`
- `lib/workspace/pipeline_state.rb` — In-flight work item tracking, disk-persisted to `~/.local/state/workspace/<name>/pipeline.json`; `.read(path)` (the raw entries, `{}` for no file, nil when unreadable) and `.reset(path)` (deletes the file) serve `pipeline status` and `pipeline reset` with no instance
- `lib/workspace/sentinel_poller.rb` — Background poller watching tmux panes for `WORKSPACE_DONE:` sentinel
- `lib/workspace/spine_watcher.rb` — agentd's watch of a workspace's `spine/` (stat polling, settle, baseline like `PlanProgressWatcher`): logs `spine_changed` for status/note changes and `added`/`removed` stage files made any way; skips a change whose revision is the newest `spine set` line for that path in the event log (`EventLog#recent`)
- `lib/workspace/agent_recovery_desk.rb` — The daemon's recovery of a Claude Code agent whose turn ended on an API error (`turn_failed`), a shell over its parts (`facts:`, `intake:`, `confirmer:`, `runner:`, `outcomes:`, `store:`, `restarting:`, `clock:`, `logger:`, all built by `AgentRecoveryDeskFactory.assemble`): hands hook events to `RecoveryIntake`, has `RecoveryConfirmer` mark the failed panes, confirm a waiting failure against the transcript after 30s and pick up a lost attempt, and `#check` answers `:go`/`:defer`/`:clear`/`:never`, making its reads in order through `RecoveryFacts` and asking `RecoveryVerdicts` what each means; an answer but `:go` goes to `RecoveryOutcomes#refuse`, a `:go` to `RecoveryAttempts#start` (given the desk's check), and the resume line a `:go` carries is `RecoveryAttempts#resume_line`; the first attempt of an outage types a message at the live prompt, the later ones stop the agent with one SIGINT, type the resume command and a message; gives up with one inbox item (`attempts_exhausted`, `not_retryable`, `cannot_restart`, `fresh_conversation`, `deferred`, `unconfirmed`); writes `agent_recovery_attempt` and `agent_recovery_gave_up`; docs in `docs/README.agentd.md`; public `#session_event`, `#scan`, `#holding?`, `#check`; its spec builds it through `AgentRecoveryDeskFactory.assemble`, where `steps:` (an `AgentRecoverySteps`) and `max_attempts:` force an outcome without stubbing a part
- `lib/workspace/permission_escalation_desk.rb` — `PermissionEscalationDesk`: a desk in `HookFanout`'s `desks:` (built per workspace by `build_agentd_parts` when given `permission_policy_config:`, over `inbox_store:`, `policy_config:`, `workspace:`, `project:`, `monitor:`, `clock:`, `logger:`); `#session_event` upserts (with `reopen: true`) an `alert` item keyed `permission:<ws>:<pane>:<agent_id or main>`, titled "<ws> pane <pane>: <tool> needs permission", for a Claude `permission_request` event or a Codex `notification` with `notification_type: permission_request` whose `decision` is `ask`, or absent while `policy_config.configured?` (read at most every `CONFIGURED_TTL` seconds); allow, deny, unconfigured and other notifications open none; the body is the first line of the `ToolInputSummary` text (capped) and the rule; any other event but `permission_request` and `notification` closes that agent's item by key (`done`, by `permission_escalation`), only for items this desk opened; `#scan` closes open `permission:<ws>:` items whose pane shows no wait for that agent in `monitor.snapshot`, once older than `GRACE` seconds; every error is logged and swallowed; specs `spec/unit/workspace/permission_escalation_desk_spec.rb` and `spec/integration/workspace/permission_escalation_desk_spec.rb`
- `lib/workspace/recovery_verdicts.rb` — `RecoveryVerdicts`, the pure decisions of each stage of `AgentRecoveryDesk#check` (module functions over an entry Hash, an agent Hash, a screen, a transcript or ledger record, a Time; no I/O, no clock): `signalled_lately?`, `started_since_signal?`, `resumable?`, `same_process?`, `prompt_after?`, `subagents_recent?`, `screen_busy?`, `first_attempt?`, `transcript_verdict`, `session_verdict` and `start_command_verdict` (`:defer`, `:clear`, `:never` or nil to go on), `time_of`; holds `SUBAGENT_QUIET` and `BUSY_SCREEN`; spec `spec/unit/workspace/recovery_verdicts_spec.rb` over plain values; `signalled_lately?(signalled, now)` takes the parsed signal time, so the desk parses `last_signal_at` once and reads the clock only when it parses; the desk parses its times with `time_of`; flat until T50
- `lib/workspace/recovery_facts.rb` — `RecoveryFacts`, each read `AgentRecoveryDesk#check` makes, one named method per read, each read only when called: `pane_detail` (`Hash`, nil or `:unknown`), `tree` (the process table, nil and logged when unreadable), `agent(detail)` (the table, then the agent under the pane: an `Agent` of `found` and `tree`, nil when the table can't be read), `foreground?`, `held_off?` (input line, prompt since the failure, sub-agents, then the screen's capture-sleep-capture, stopping at the first that holds), `still_screen`, `pane_clear?`, `prompt_since_failure?`, `prompt_after?`, `transcript_file?`, `transcript_error` (the last turn record), `ledger_start` (a session's last start), `ledger_session` (the record open in the pane, `:unreadable`), `start_command` (`:gone`), `live_agent(pane_id)` (`pane_detail` then `agent`, nil when either can't be read), `session_held?(session_id)` (the table, then `AgentStopper#session_held?`; an unreadable table counts as held, for `RecoveryAttemptRunner`), `session_held_in?(session_id, tree)` and `restartable?(agent, detail, tree)` (`AgentStopper` over a table already read, for `#check`); built by `AgentRecoveryDeskFactory.assemble`; spec `spec/unit/workspace/recovery_facts_spec.rb` over `RecordingProcessTree`, `RecordingRecoveryStopper`, `RecordingRecoveryLedger`, `RecordingTurnTranscript`, `RecordingRecoveryMonitor` and `RecordingInputCheck` (`spec/support/fakes/recovery_facts.rb`, sharing one `calls` log for the read order, each in `fake_contract_spec`), `FakePaneFactory` and `FakePane`; flat until T50
- `lib/workspace/recovery_intake.rb` — `RecoveryIntake`, the recovery desk's intake of hook events, skipping a review window's pane (`delivery_facts` `:review`) (`store:`, `session_monitor:`, `facts:`, `report_give_up:`, `resolve:`, `rebind_queue:`, `max_attempts:`, `clock:`, `spawn:`, `logger:`): `#session_event` queues an event for one worker (`@queue_guard`; the empty-queue check and the worker's end one step in `next_message`), which applies `turn_failed`, `stop`, the agent-at-work events, `session_start`, `session_end` and sub-agent events to the pane's `AgentRecoveryStore` entry; a failed turn is applied through `RecoveryEntry.apply_failure`; a give-up and a resolved item go through the `report_give_up:`/`resolve:` callables (`RecoveryOutcomes`' methods, given by `AgentRecoveryDeskFactory.assemble`); spec `spec/unit/workspace/recovery_intake_spec.rb` over `RecordingRecoveryStore` and `RecordingAgentFacts` (`spec/support/fakes/recovery_intake.rb`) and `RecordingRecoveryMonitor`, each in `fake_contract_spec`; flat until T50
- `lib/workspace/recovery_confirmer.rb` — `RecoveryConfirmer`, the recovery desk's confirmation of its entries from the monitor's scan (`workspace:`, `store:`, `facts:`, `session_monitor:`, `marker:`, `clear:`, `report_give_up:`, `resolve:`, `event_log:`, `max_attempts:`, `clock:`): `#mark_failed_panes(entries)` marks again, through `SessionMonitor#mark_turn_failed`, the panes failed when the desk started (listed on the first call only, a pane the monitor doesn't know kept for the next); `#settle(pane_id, entry)` reads, `SETTLE` (30s) after the failure, the transcript's error uuid, the agent and the ledger's cwd through `RecoveryFacts`, clearing on a recovered turn or another session; `#reconcile(pane_id)` takes an `attempting` entry no claim holds back to waiting (or a give-up) with an `agent_recovery_attempt` line, outcome `interrupted`, deciding nothing on a read that can't be made; a clear, a give-up and a resolved item go through the `clear:`/`report_give_up:`/`resolve:` callables (`RecoveryOutcomes`' methods, given by `AgentRecoveryDeskFactory.assemble`); `SETTLE` and its own `ATTEMPT_EVENT` (the same line name as `RecoveryOutcomes::ATTEMPT_EVENT`); spec `spec/unit/workspace/recovery_confirmer_spec.rb` over `RecordingRecoveryStore`, `RecordingRecoveryMonitor`, `RecordingConfirmerFacts`, `RecordingStopMarker` and `RecordingRecoveryEventLog` (`spec/support/fakes/recovery_confirmer.rb`), each in `fake_contract_spec`; flat until T50
- `lib/workspace/recovery_attempt_runner.rb` — `RecoveryAttemptRunner`, steps 2 to 5 of a recovery attempt on the attempt's own thread (`panes:`, `session_name:`, `store:`, `facts:`, `session_monitor:`, `readiness:`, `detector:`, `marker:`, `prompt_typer:`, `delivery_lock:`, `restarting:`, `rebind_queue:`, `clock:`, `sleeper:`): `#restart(attempt)` waits for the stopped agent to leave (`STOP_WAIT`, `CLEAR_READS`), types `C-u` and the resume line through the `Pane`, waits for the agent (`AgentReadiness`, `READY_WAIT`), stores it, clears the marker and moves the queue, then types the message; `#typed(attempt)` types the message through `PromptTyper` under the delivery lock (claim, agent and terminal read again before each paste and Enter, `TYPE_TRIES`) and waits `PROMPT_WAIT` for the `user_prompt` hook; an agent it didn't start is `person_resumed` or `fresh_agent` (`SESSION_WAIT`); both answer `[outcome, agent]`; `#rebind(pane_id)` moves a pane's queued prompts to the monitor's agent pid (step 6, `RecoveryOutcomes#finish`, calls it too); `Attempt` (`#ours?(agent)`, `#current?(entry)`) is the value step 1 (`RecoveryAttempts`) builds; built by `AgentRecoveryDeskFactory.assemble`, and `AgentRecoverySteps` picks it or a fixed runner; reads through `RecoveryFacts`, entry writes through `RecoveryEntry`; spec `spec/unit/workspace/recovery_attempt_runner_spec.rb` over `RecordingAttemptFacts`, `RecordingReadiness` and `RecordingAttemptTyper` (`spec/support/fakes/recovery_attempt_runner.rb`), `RecordingRecoveryStore`, `RecordingRecoveryMonitor`, `RecordingStopMarker`, `FakePaneFactory` and `FakePane`, each in `fake_contract_spec`; flat until T50
- `lib/workspace/recovery_outcomes.rb` — `RecoveryOutcomes`, what comes of a recovery check or attempt (`workspace:`, `store:`, `facts:`, `inbox:`, `runner:`, `event_log:`, `max_attempts:`, `clock:`, `logger:`): `#refuse(pane_id, seen, answer)` (`:defer` stamps `defer_since` and gives up `deferred` after `DEFER_LIMIT` (1800s), `:clear` deletes an entry with no attempts or gives up `unconfirmed`, `:never` gives up `cannot_restart`; an entry a hook changed is left alone), `#clear`, `#report_give_up` (the `agent_recovery_gave_up` line, then one inbox item keyed `agent-recovery:<session>`, reopened, resolved again when the entry moved on meanwhile; an inbox error logged), `#resolve`, `#finish` (step 6: reads the pane through `RecoveryFacts`, moves the queue through `RecoveryAttemptRunner#rebind` for an agent not the attempt's, one store update taking what hooks left (`RecoveryEntry.apply_failure` for a turn failed during it) ahead of the outcome, then the `agent_recovery_attempt` line (`ATTEMPT_EVENT`) and the item) and `#take_back` (a step 1 whose signal never went out, put back as it was); `RecoveryIntake` and `RecoveryConfirmer` report through its methods; spec `spec/unit/workspace/recovery_outcomes_spec.rb` over `RecordingRecoveryStore`, `RecordingConfirmerFacts`, `RecordingRecoveryInbox`, `RecordingStepRunner` and `RecordingRecoveryEventLog` (`spec/support/fakes/recovery_outcomes.rb`, each in `fake_contract_spec`); flat until T50
- `lib/workspace/recovery_attempts.rb` — `RecoveryAttempts`, one recovery attempt from its claim to its end (`store:`, `facts:`, `outcomes:`, `attempt_runner:`, `steps:`, `stopper:`, `marker:`, `resume_command:` (the workspace bound by the factory), `delivery_lock:`, `claim_restart:`, `release_restart:`, `spawn:`, `clock:`, `logger:`): `#start(pane_id, mode, check:)` spawns, claims the pane, runs step 1 (a quiet screen, the desk's check under the delivery lock, the failure confirmed through `RecoveryFacts`, `attempting` written with `TYPED_MESSAGE`/`RESUMED_MESSAGE`, for a restart the marker and one SIGINT through `AgentStopper#stop`, any other answer taken back through `RecoveryOutcomes#take_back`), the steps 2 to 5 runner `AgentRecoverySteps` picks, then `RecoveryOutcomes#finish`, and always releases the claim; `#resume_line(entry)` builds the line `#check` answers; a refusal goes to `RecoveryOutcomes#refuse`; spec `spec/unit/workspace/recovery_attempts_spec.rb` over `RecordingRecoveryStore`, `RecordingOpeningFacts`, `RecordingRecoveryOutcomes`, `RecordingStepRunner`, `RecordingRecoveryStopper` and `RecordingStopMarker`, each in `fake_contract_spec`; flat until T50
- `lib/workspace/recovery_entry.rb` — `RecoveryEntry`, the entry writes more than one recovery part makes (module functions changing the entry Hash given, inside the caller's `AgentRecoveryStore#update`): `store_agent`, `give_up`, `forget_signal`, `schedule_next(entry, max_attempts:, clock:)` (the clock read only when an attempt is scheduled), `unreported?`, `signalled_lately?(entry, clock)`, `apply_read`, `agent_gone?`, `same_wait?`, `apply_failure(entry, session_id, error, transcript_path, live, max_attempts:, clock:)` (one failed turn: marked on an attempt, `not_retryable` given up, a give-up reopened, else scheduled) with `RETRYABLE_ERRORS`, `agent_came_back?`, `other_agent?`; `RecoveryIntake`, `RecoveryConfirmer` and `RecoveryOutcomes` write through it; `give_up` stamps `gave_up_at` from the clock so a reader can tell this give-up from a later failure; the readers' shared trust rules: `of_session(entry, session_id)`, `trusted_for_failure(entry, session_id:, failed_at:)` (an entry of that session; a `gave_up` one only when its `gave_up_at` is at or after the failure, so an older give-up, one with no `gave_up_at` or a failure of unknown time is not trusted) and `failure_since(shown_since, entry, session_id)` (the pane row's `turn_failed_since`, else the entry's `failed_at`), used by `WorkflowSweep` and `WorkflowStatus`; spec `spec/unit/workspace/recovery_entry_spec.rb` over plain values; flat until T50
- `lib/workspace/agent_recovery_store.rb` — Flock-guarded `agent-recovery.json` per workspace: one entry per pane (phase, attempts, error, session, agent pid), the 12-attempt schedule (`MAX_ATTEMPTS`, waits 60s doubling to 900s), temp file and rename; `#update` always yields the entry
- `lib/workspace/agent_recovery_config.rb` — Reads `agent.recovery.enabled` (global, project, worktree; default true) for the daemon, once at its start; a bad stored value falls back to the default with a warning
- `lib/workspace/agent_daemon_stopper.rb` — Stops one workspace's `agentd` from its name alone: finds the socket's holder, checks it is that workspace's `agentd`, sends SIGTERM and waits up to `stop_timeout` for the socket to stop answering. `#call(name:)` returns a frozen `Result` (`status` :stopped, :not_running, :refused or :timed_out; `pid`; `message`). It refuses, signalling nothing, when `lsof` does not answer, finds more than one holder, or finds none while the socket answers; when the holder's argv lacks `agentd`; when its `--name NAME`, `--name=NAME` or trailing positional names another workspace (`WorkspaceName.same?`); and for this process's own pid. Needs no config file, so it works after Kill or Prune removed one. `#find_pid`, `#socket_pids`, `#holder` (argv checks, as a `Holder`) and `#terminate` are the pieces `Commands::Daemon` uses for `status`, `list` and `restart`; the default pid finder runs `lsof -t` under `lsof_timeout`. Built once in `Workspace.build_cli`; spec `spec/unit/workspace/agent_daemon_stopper_spec.rb` with injected lambdas. `AgentDaemonStopper.served_name(words)` is the one reader of the workspace name from an `agentd` command line (string or words), which `doctor`'s `agentd-orphans` check shares.
- `lib/workspace/agent_stopper.rb` — Finds the Claude Code process in a pane and sends it SIGINT, nothing else (any other signal starts a new conversation in a `claude ... || claude` pane); checks pid and start time, refuses an agent whose process group doesn't hold the terminal (`#foreground?`), and says whether the pane is clear (`#pane_clear?`)
- `lib/workspace/agent_resume_command.rb` — The one builder of the shell line that resumes a Claude Code session (the pane's configured command, `--resume ID`, the carried flags), shared by `restore` and the recovery desk; a value that isn't a session id never reaches a command line

- `lib/workspace/hook_event_log.rb` — One agent daemon's high-rate log of hook events: `<dir>/<workspace>.jsonl`, one typed JSON line per tool start and finish, permission request and how it ended, notification, sub-agent start and stop, session start and end, and prompt submitted, plus the `agent_status` lines agents post (`agent status post`). `workspace events` reads it, together with the lifecycle event log, which never sees these lines. - `lib/workspace/daemon_watch.rb` — One stream of a workspace's workflow decision lines and its runs' events, oldest first, with one cursor that resumes both; `daemon watch` reads it. It composes an `EventStream` built with `workspace:` and `lifecycle_path: nil`, so only that daemon's hook file is read, and yields only the decision types (`DECISION_TYPES`: `workflow_advance_started`, `workflow_run_skipped`, `workflow_sweep_started`, `workflow_process_exited`) and the stream's gap lines. The runs are the workspace's going runs when it opens, plus any it finds going every `DISCOVER_EVERY` (8) reads; each is read by line number through `WorkflowRunStore#events`, wherever the archive moved it, until its state file is in the archive (`WorkflowRunStore#archived?`, read before its events; never the terminal state alone, which a finishing change writes before its last history lines and the archive's renames) and its history is drained; between the archive's two renames its history reads as empty and is read again next time. A drained run moves from the cursor's `r` to `d`; a run gone from the store is dropped (with `run:`, it ends the watch: `done?`). If moving a finished run to the archive fails, the watch keeps waiting for it until a later change archives it; Ctrl-C stops the reader. A few writers append a run's history lines without the run's lock, so a line appended just after the run is archived and drained may not be shown. Each look for runs takes every run of the workspace still in the runs directory (`WorkflowRunStore#unarchived`, finished or not, so a run whose terminal state is written but that is not yet archived is not missed), then the archived runs that ended within `FINISHED_MARGIN` (60 s) of the last look (read through `WorkflowRunStore#finished_since`, which parses only state files modified since) (a resumed cursor's `t`) and are not in `d`, so a run that started and ended between two looks or between two watches is read once; `d` keeps a run until it ended over `FINISHED_MARGIN` before the last look. A watch opened without a cursor puts the runs that had already ended in `d`, so it never reads them. With `run:` only that run is followed (an unknown one raises `unknown_run`; no archived runs are scanned), only decision lines whose `run_id` or `run_ids` name it are yielded, it stays in the cursor, and `done?` says when it is finished and drained. Lines are merged by time (`at` for the daemon's, `ts` for a run's), keeping each source's own order. Each yielded line is `{"source" => "daemon" | "run" | "watch", "at", "type", "workspace", "run_id" (nil for a sweep line or a gap), "event" (the line as its file holds it; a run event keeps `n`), "cursor"}`. The cursor is `w1.` then `EventStream.encode_cursor`'s body over `{"w" => workspace, "f" => the run filter or nil, "e" => the EventStream's cursor, "r" => {run id => line number}, "t" => last look for runs, "d" => {drained run id => ended_at}}`; the `w` keeps a `workspace events` cursor and this one from being taken for each other, and a cursor that can't be read, names another workspace or another run filter, or carries an inner cursor `EventStream` refuses raises `EventStream::InvalidCursor` (`invalid_cursor`). Without a cursor it opens at the end of each source (`at: :end`) or their start (`at: :start`); a run a cursor doesn't name is read from its start.
- `lib/workspace/permission_policy.rb` — `PermissionPolicy`, a pure engine over ordered `{source:, rules:, default:}` layers; `decide(tool_name:, tool_input:, cwd:)` returns `{action:, rule:}`. A rule's `tool` is a `File.fnmatch` glob; Bash patterns match each piece from `BashCommandPieces` (`FNM_DOTMATCH`), file-tool patterns match the expanded path (`FNM_PATHNAME | FNM_DOTMATCH`, `~` expanded), and `deny`/`ask` also match the symlink-resolved path while `allow` needs both. Deny beats ask beats allow across all layers; the first match of the winning action names the rule; with no match the most restrictive layer `default` applies, else `ask`. A Bash allow by pattern needs every piece to match an allow pattern and never holds for a command with a substitution or file redirection (that gets deny or ask, not `default: allow`). Errors propagate to the caller.

A finished run counts as having no rules. `#configured?(workspace:, project:)` is true when any layer holds either key or the live bound run has `permissions` rules, reading presence only so an invalid value still counts; a layer file that can't be parsed also counts as true; it is false only when presence could not be read for another reason (logged). It reads files only: no daemon, no network, no `git`.
