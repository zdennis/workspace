# CLI

CLI dispatch, the verb-family parsers under `lib/workspace/cli/`, the `build_cli` composition root and the CLI spec tooling. Full per-file detail, moved verbatim from `.claude/CLAUDE.md`; the one-line index there links here.

- `bin/workspace` — Entry point (4 lines), calls `Workspace.build_cli.run(ARGV)`
- `lib/workspace.rb` — Module root, `build_cli` factory (the streams `output:`, `error_output:`, `input:`, `env:`, and the named overrides `exit_handler:`, `tmux:`, `task_store:`, `skill_source:`, `launchctl:`, `logger:`, `osascript:` (the AppleScript runner `ITerm` and `WindowManager` share), `ui_osascript:` (the JXA runner of `ui status`), `sleeper:` (`relaunch`'s pause), `detacher:` (`relaunch`'s background run, a `DetachedSpawn`), each nil builds the real one, for specs); it builds the shared `ScanSlotLimiter`, `RestartRegistry` and `SessionMonitorBuilder` and gives them to `ContextReader`, `build_agentd_parts` and `Commands::Agent`; the public `build_agentd_parts(**shared)` beside it returns the agent daemon's per-workspace builder (given `workspace:`, `session_name:`, `delivery_lock:`, `registry:`, `recovering:`, a frozen `AgentdParts`; `pipeline_desk:` reuses a desk an earlier call built, `pipeline_only: true` builds that desk alone; the restart desk and runner read `pipeline_ref` from the pipeline desk; it only constructs, `Commands::Agent#call` starts the parts), taking each part's factory (nil builds the real desk, runner or watcher), the sub-parts `agent_restart_factory:`, `context_reader:` and `handoff_typer:`, the hook fan-out's `workflow_nudger:`, the work queue desk's `work_queue_desk_factory:` and `workflow_store:` (nil builds a run store over the config's run dirs), and the pipeline desk's `work_coordinator_client:`, `pipeline_config:`, `pipeline_state:`, `sentinel_poller_factory:`, `token_generator:`, `epoch_generator:` (its registration and re-registration epochs), `clock:` and `retry_backoff:`, called by `build_cli` and `spec/support/agentd_parts_helper.rb`; the public `build_agent_daemon` beside it builds `Commands::Agent` over that builder, with its `AgentdSocketServer` (`signal_trapper:`, `socket_poll_interval:`, `workflow_tick_passes:`), the `router_for` lambda that builds each workspace's `AgentdRouter`, and the `claude_pane` lambda (a `TmuxPane` search over `agent_labels:`/`agent_commands:`), and `current_name:` calls `Commands::Agent#prepare`; called by `build_cli` and the helper; the public `build_workflow_engine` beside it (today's engine keywords; `review_runner:` builds the `WorkflowReviewRound` over the engine's own change, store and prompt and makes it the `review_round`/`review_closer` not given (those two are spec-only overrides), `round_holder:` the round's `holder`, `holder_alive:` the `WorkflowDecisions` liveness check) builds the `WorkflowEngine` and its phases over one `WorkflowRunChange`, called by `build_cli`, the simulator's `engine_factory` and the specs that drive a whole engine; error classes `build_cli` builds one key presser, `->(workspace, pane, keys) { send_command.deliver(...) }`, before the engine and gives it to `build_workflow_engine` (`interrupter:`, for `pause --interrupt`; its default raises `Workspace::Error` ("cannot interrupt"), so the simulator and the specs build unchanged and a pause asked to interrupt there reports `interrupted: false` and keeps no mark) and to `WorkflowSweep` and `WorkflowReviewSweep`; it also builds `WorkflowRecover` beside the sweep, over a quiet `Commands::Restore` (`output: StringIO.new`) and `tmux.session_name_for`, and gives it to `Commands::Workflow` as `recover:`.
- `lib/workspace/cli.rb` — CLI dispatch, OptionParser definitions, simple command methods; `ROUTES` maps a verb to the key of its family parser in `families:` (today `workflow` and `step` to `:workflow`; `agent`, `agentd`, `daemon`, `sessions` and `review` to `:agent`; `agent-run` and `handoff` to `:agent_run`; `pipeline` to `:pipeline`; `plan`, `spine`, `journey` and `goal` to `:plan_spine`; `template` to `:template`), which `#run` calls with the verb, its arguments and the `Invocation` before its own `case`; `common:`, `names:` and `launcher:` are built by `build_cli` and shared with the families; `cmd_relaunch` deletes `WORKSPACE_RELAUNCH_DETACHED` from its invocation's env and `ENV` first (it counts only `1`; the sessions the run launches never inherit it), and hands a relaunch whose target's tmux session holds the caller to `Relauncher#detach` (`relaunch_includes_caller?` over `Relauncher#own_workspace` with no working-directory match) unless it was set
- `lib/workspace/cli/invocation.rb` — `CLI::Invocation`, a frozen value of one run (`output`, `error_output`, `exit_handler`, `help_asked`, `quiet`, `env`), which `CLI#run` builds once per run (the nested run of `--help --json` builds its own over the buffers); the helpers that write or exit take it
- `lib/workspace/cli/common.rb` — `CLI::Common`, the output, exit, help and editor helpers (`run_action`, `divert_output`, `action_row`, `exit_code_row`, `emit_json_error`, `emit_json_usage_error`, `help_requested?`, `verb_help_shown?`, `json_requested?`, `parse_duration_option`, `run_row_action` (one row, or nil as `cancelled`), `refuse_bad_bytes!`, `open_in_editor(invocation, *paths)` (runs `$VISUAL` or `$EDITOR` as an argv array and answers true, or prints the paths and answers false with no editor, under `--no-input` or off a terminal; `editor_failed`; `config edit` and `template edit` call it); `ACTION_JSON_SCHEMA_VERSION`); `input:`, `editor_launcher:` and `interactive:` are its only state (`build_cli` passes `input:` and its `editor_launcher:`; nil builds `system` and a tty check); `build_cli` builds one, shared by `CLI` (whose private helpers of those names delegate to it) and the families
- `lib/workspace/cli/names.rb` — `CLI::Names` (`project_config:`, `project_detector:`, `lineage:`, `working_dir:`, `workspace_name:`), the name and working-directory helpers (`given_name`, `settle_name`, `take_known_workspace!`, `pick_workspace_name`, `single_workspace_arg`, `require_known_workspace!`, `working_dir_for`, `dev_working_dir`, `current_workspace!`, `workspace_here`); the ones that read the run's flags or print "Workspace 'x' is y." take the `Invocation`; `build_cli` builds one, shared by `CLI` (which delegates to it) and the families
- `lib/workspace/cli/launcher.rb` — `CLI::Launcher` (`project_config:`, `launch_command:`, `launch_mode:`, `state:`, `project_settings:`, `hook_runner:`, `common:`, `working_dir:`, `library:`, `instruction_composer:`, `name_migration:`, `hook_check:`), what every launching verb shares: `#launch(invocation, args, ...)` settles mixed-case names through `NameMigration`, resolves the plays and composes the packs before any config is made, calls `Commands::Launch`, then makes each settings file and runs `post_launch`, then asks the optional `hook_check` (a `LaunchHookCheck`, called bare — its own rescue keeps an unreadable settings file from failing the launch) to check each launched project's checkout, with the root the args resolved to, else `project_config.project_root_for`, and the invocation's error output as the io the notes go to (warnings on the invocation's error output); `#launch_missing(invocation, names)` launches the workspaces whose session is gone, headless ones headless, and answers workspace => why it could not be launched (moved from `CLI#launch_for_restore`, which now calls it; `restore` and `workflow recover` use it); `#rows` is the `results` rows from the state Launch wrote; `build_cli` builds it over the same `Common`, and `launch`, `relaunch`, `restore` and the `spine start`, `promote --launch` and `plan start` launcher lambdas call it
- `lib/workspace/launch_hook_check.rb` — `LaunchHookCheck` (`hook_installer:`, `hooks_config:`, `which:`), the read-only warning every launch prints when a hook-capable agent (`AgentProvider.all.select(&:supports_hooks?)`) whose executable is on PATH holds no current session hooks in the checkout at `root`: installed counts as the current `HOOK_COMMAND` hooks in the tracked or user settings file (`HookInstaller#installed?`) **or** in the local settings file `start` installs into (`installed_in?`, the new public read; never read for a user-scoped agent, which has no local file); silent when installed and `stale_tracked_hooks?` is false, otherwise one Note line — a stale tracked entry is `HookInstaller#stale_message`, which `Commands::Start` shares, everything else reads "<label> hooks missing or stale for this checkout's agents; run `workspace init --install-hooks` in this checkout to install them." (`FIX_HINT`; init is the one command that installs both a project-scoped agent's settings hooks and a user-scoped agent's user-level hook file, which `doctor --fix` does not), and a `Workspace::Error` from an unreadable settings file is rescued here to a note, so it can never fail a launch or a restore; it installs nothing; `check(root, io:)` takes the io per call because `build_cli` builds the checker once and `CLI::Launcher` passes the invocation's error output; a `hooks_config` given skips the provider `codex.hooks.install` is off for, exactly as `Commands::Start` skips it, and nil skips nothing; spec `spec/integration/workspace/launch_hook_check_spec.rb`
- `lib/workspace/cli/relauncher.rb` — `CLI::Relauncher` (`stop_command:`, `hook_runner:`, `launcher:`, `state:`, `sleeper:`, `tmux:`), the work of `relaunch` apart from its option parsing: `#call(invocation, names, only_stopped: false)` prints `Will relaunch: ...`, stops the workspaces (`post_stop` hooks for those stopped), sleeps 2s, launches the windowed batch then the headless one (`headless: true`) through `CLI::Launcher#launch`, both attempted even if the first fails, and answers `{exit_code:, results:, warnings:}` (one `relaunched` row per workspace from `CLI::Launcher#rows`, always built; `warnings` from the stop command, which `cmd_relaunch` ignores); `only_stopped: true` (`template apply|restore --relaunch`) checks each session through `tmux:` after the stop (the stop command answers its names whether or not tmux killed the session) and answers a `failed` row, reason `relaunch_stop_failed`, without launching, for one still up; headless is read before the stop takes the state entries; `#active_name(name)` loads the state and answers its key that `WorkspaceName.same?` matches, nil when inactive; `#running?(name)` is `Tmux#session_exists?` under `Tmux.stored_session_name` (an error counts as up); `#pane_in_session?(pane_id, name)` asks `Tmux#session_name_for_pane(project: name)` (the workspace's own socket) and compares both names through `Tmux.stored_session_name`, nil when tmux can't say; `sleeper:` is required, and `build_cli`'s `sleeper:` override (nil builds the real one) feeds it; `build_cli` builds it once beside `launcher` and gives it to `CLI` and `CLI::Template` (`relauncher:`); `#own_workspace(env, here, tally = nil)` is the one test of the caller's own workspace (here, then `$TMUX_PANE` through `#pane_in_session?`, else `$TMUX` through `#client_session`/`#session_of?`, read once; unknown counts as not), shared by `cmd_relaunch` (here nil: only tmux decides) and `CLI::Template` (here the working directory's workspace); `#detach(names)` checks `detacher:` and `log_dir:`, then that each `program:` file (Ruby and `bin/workspace`, from `SkillSource.stable_dir`: the Homebrew `opt` keg when inside a Cellar keg) exists and is executable, then under a `FileLock` in `log_dir:` (`Config#relaunch_log_dir`) calls `#refuse_in_progress!`, starts `relaunch -- NAMES...` through `detacher:` (a `DetachedSpawn`; `DETACHED_ENV` `WORKSPACE_RELAUNCH_DETACHED=1` set), writes each workspace's `<name>.pid` record (`pid`, `started` from `processes:` (`LockHolder#start_time`), `log`) and keeps the newest `LOGS_KEPT` (20) logs, answering `{pid:, log:}`; `relaunch_detach_failed` with no detacher or log dir, a missing program (`details.program`) or a `SystemCallError` before the run started; `#refuse_in_progress!(names, except_own: false)` raises `relaunch_in_progress` (`names`, `pid`, `log`) for a record whose process `LockHolder#alive?` says is live (unreadable counts as live, a dead one is ignored; `except_own` skips `wrapper_pid:`'s, `Process.ppid`); `#release(names)` deletes the records naming that wrapper; `cmd_relaunch` checks `#refuse_in_progress!` in the foreground, detaches when a target is the caller's own and the marker was not `1` (rows `relaunch_scheduled`, `extra` `log`/`pid`), and in the background run checks `except_own: true`, relaunches and `#release`s; spec `spec/unit/workspace/cli/relauncher_spec.rb` over doubles, `cmd_relaunch` in `spec/unit/workspace/cli/relaunch_spec.rb`
- `lib/workspace/detached_spawn.rb` — `DetachedSpawn#call(argv, log_path:, env:)`: a Ruby wrapper (`ruby:`, `spawner:`, `reaper:`) that calls `Process.setsid`, runs the command and appends its exit to the log; stdin `/dev/null`, stdout and stderr the log (0600, directory 0700), `TMUX`/`TMUX_PANE` removed; answers the wrapper pid (`Process.detach`ed); `Workspace.build_cli`'s `detacher:` override (nil builds it); spec `spec/system/workspace/detached_spawn_spec.rb`
- `lib/workspace/cli/workflow.rb` — `CLI::Workflow`, the `workflow` and `step` family (`workflow_command:`, `workflow_start_command:`, `workflow_project:`, `status_scope:`, `config:`, `project_config:`, `project_detector:`, `git:`, `launch_mode:`, `common:`, `names:`, `input:`, `working_dir:`, `launcher:` (a `CLI::Launcher`, for the launch block of `workflow recover`)): `#call(verb, args, invocation)` parses the verb, fills a left-out RUN or ID from {Commands::Workflow#default_run} and `#default_workflow` for the verbs `RUN_DEFAULTS` and `DEFINITION_DEFAULTS` name (the workspace from the working directory alone, `not_in_workspace` read as none, so an unresolvable id keeps the `needs` table's usage error); `--name` or `--project` stops the defaulting, `graph --run RUN` takes its ID from that run and bare `show` never defaults, refuses what it has no use for (`SUBCOMMANDS`, `--interrupt` and `--reason` for `pause` alone, the `--source N` position of `install`, `--dry-run` for `install`, no argument for `uninstall`, no RUN or `--name` for `recover`, which passes `launcher.launch_missing` as its launch block) and hands the values to `Commands::Workflow` or `Commands::WorkflowStart`, writing and exiting only through the invocation; `edit` opens the file `Commands::Workflow#edit` resolves through `CLI::Common#open_in_editor` (`$VISUAL`, else `$EDITOR`, else the path is printed) and under `--json` passes no opener so only the action row answers; `.inputs(pairs)` is the `--input KEY=VALUE` reader `go` and `start --recipe` share; `build_cli` builds it, and `CLITestHelpers.build_cli` builds it from the old `workflow_command:`/`workflow_project:` keywords for the `CLI.new` specs; spec `spec/unit/workspace/cli/workflow_spec.rb` over `RecordingWorkflowProject`, `RecordingStatusScope` and `RecordingProjectDetector` (`spec/support/fakes/cli_workflow.rb`, each in `fake_contract_spec`) and the CLI fake commands; the examples that go through `CLI#run` (its rescue funnel, the help pages, a real `StatusScope`, real `Commands::Workflow` over temporary directories) are in `spec/integration/workspace/cli/workflow_spec.rb`, and `workflow advance` as the daemon's `WorkflowNudger` starts it (a real `WorkflowGuard`, which runs git) in `spec/system/workspace/cli/workflow_advance_spec.rb`; `run` and `start` take `--file PATH` in place of the ID (`--file` with a `start` REF positional or with `--ref` is a usage error).
- `lib/workspace/cli/agent.rb` — `CLI::Agent`, the `agent`, `agentd`, `daemon`, `sessions` and `review` family (`agent_command:`, `ensure_agent_command:`, `daemon_command:`, `sessions_command:`, `review_command:`, `agent_status_command:`, `agent_executables_command:`, `agent_run:`, `project_detector:`, `common:`, `names:`, `working_dir:`): `#call(verb, args, invocation)` parses the verb and hands the values to its command, writing and exiting only through the invocation; `DAEMON_SUBCOMMANDS`; `agent run PROMPT` goes to `agent_run:`, which `build_cli` (and `CLITestHelpers.build_cli`) points at `CLI::AgentRun#prompt`, since it shares its message and sending with `agent-run command`; spec `spec/unit/workspace/cli/agent_spec.rb` over the CLI fake commands; the examples that go through `CLI#run` (its rescue funnel, `agent run`, the main help, a real `WorkspaceName`, a real `Commands::Daemon` or `Commands::Sessions`) are in `spec/integration/workspace/cli/agent_spec.rb`, built by `CLITestHelpers::AgentFamilyCli`
- `lib/workspace/cli/agent_run.rb` — `CLI::AgentRun`, the `agent-run` and `handoff` family (`config:`, `agent_client:`, `restart_agent_command:`, `send_command:`, `prompt_queue_command:`, `handoff_command:`, `project_detector:`, `common:`, `names:`, `working_dir:`): `#call(verb, args, invocation)` parses the verb and hands the values to its command, or builds the `command` or `inject` message (`AgentProtocol`), prints it and sends it through `agent_client:`, writing and exiting only through the invocation; `#prompt(args, invocation)` is `agent run PROMPT`, which `CLI::Agent` hands here; spec `spec/unit/workspace/cli/agent_run_spec.rb` over doubles; the examples that go through `CLI#run` (its rescue funnel, the main help, a real `Commands::Send` over a real `PaneLocator`) are in `spec/integration/workspace/cli/agent_run_spec.rb`, built by `CLITestHelpers::AgentFamilyCli`
- `lib/workspace/cli/pipeline.rb` — `CLI::Pipeline`, the deprecated `pipeline` family (`config:`, `agent_client:`, `common:`, `names:`, `clock:`): `#call(verb, args, invocation)` takes the subcommand as the first non-option argument, prints `DEPRECATION` on the invocation's error output (in the action document's `warnings` under `--json`), reads and resets the state file through `PipelineState.read`/`.reset`, and sends the `command` and `inject` messages (`AgentProtocol`) through `agent_client:`, the `AgentMessageClient` `build_cli` shares with `CLI::AgentRun`; writing and exiting only through the invocation; spec `spec/unit/workspace/cli/pipeline_spec.rb` over a double client and a temporary state directory; the examples that go through `CLI#run` (its rescue funnel, a real `AgentMessageClient` over a Unix socket the example answers) are in `spec/integration/workspace/cli/pipeline_spec.rb`, built by `CLITestHelpers::AgentFamilyCli`
- `lib/workspace/cli/plan_spine.rb` — `CLI::PlanSpine`, the `plan`, `spine` (`journey`) and `goal` family (`plan_command:`, `plan_dispatch_command:`, `plan_task_command:`, `spine_command:`, `spine_init_command:`, `spine_start_command:`, `goal_command:`, `status_scope:`, `project_detector:`, `launcher:`, `common:`, `names:`, `working_dir:`): `#call(verb, args, invocation)` parses the verb (`PLAN_FLAGS`, `PLAN_TASK_FLAGS`) and hands the values to its command; `plan start` and `spine start` get a launcher lambda over `CLI::Launcher#launch` with the invocation; writing and exiting only through the invocation; spec `spec/unit/workspace/cli/plan_spine_spec.rb` over doubles; the examples that go through `CLI#run` (its rescue funnel, the help pages, a real `StatusScope`) are in `spec/integration/workspace/cli/plan_spine_spec.rb`, built by `CLITestHelpers::PlanSpineFamilyCli`; the `plan start, pause and delete` examples stay under `action --json` in the system `cli_spec.rb`
- `lib/workspace/help_pages.rb` — Data only: the help page of each verb of the commands that share one option parser (`plan`, `daemon`, `workflow`, `library`, `spine`, `binding`, `step`, `review`, `pr`, `ticket`, `goal`, `notes`, `instructions`, `ui`, `projects list`, `projects group`, `config show`), one frozen table per command keyed by verb (`usage`, `summary`, `about`, `options`, `examples`); `HelpPages.render` writes a page and the example separator, `overview_usage`/`overview_verbs` build the bare command's page from the same table, `lookup` finds the longest leading verb; `CLI#verb_help_shown?` prints a page before anything is parsed, and `help_requested?(args, page)` stops at `--` and skips the value of a flag that takes one
- `lib/workspace/json_envelope.rb` — Builds the `--json` action and error documents (`ok`, `code`, `details`, `retry`); the CLI rescue funnel emits the errors, `CLI#run_action` the actions
- `lib/workspace/output_gate.rb` — The stdout every collaborator writes through; `--json` actions divert it to stderr so stdout holds one document
- `spec/support/cli_golden.rb` — `CliGolden`, the S8 golden fixture harness: `.run(argv)` runs the CLI from `build_cli` in a throwaway HOME and working directory (PATH only Ruby's directory, empty `input:`, both osascript overrides answering as if osascript were missing), paths and version scrubbed to `$HOME`, `$CWD`, `$ROOT`, `$VERSION`; `.cases` (every `HelpExamplesSpec::PAGES` entry with `--help` and `--help --json`, every verb with `--bogus` and `--bogus --json`, the main `--bogus` and an unknown verb, and each verb bare but those in `NO_ARGUMENT_LEFT_OUT`, with the reason each is left out), one fixture file per verb; it also holds `HelpExamplesSpec::PAGES`/`ALIASES`, which `cli_help_examples_spec` checks through `CliGolden.run`
- `script/record-cli-golden` — Rewrites `spec/fixtures/cli_golden/*.txt` from `CliGolden.cases`; `spec/system/workspace/cli_golden_spec.rb` compares (system tier: `build_cli` runs git). Re-record only the fixtures a change moves on purpose (`git diff --stat spec/fixtures/cli_golden/` names them)
- `script/record-cli-coverage OUT` — Runs only the CLI specs (`spec/**/cli_spec.rb`, `spec/**/cli/**/*_spec.rb`) with SimpleCov and writes OUT: each `lib/workspace/commands/` file's line coverage from that run and the `Workspace::Commands` public methods it called, traced by `spec/support/commands_method_trace.rb` (on only when `WORKSPACE_TRACE_COMMANDS` names a file); T39's answer is `spec/fixtures/cli_coverage_t39.json`, which T48 compares against
- `spec/support/cli_test_helpers.rb` — The CLI's spec fakes (each fake command held to its `Commands::*` class in `fake_contract_spec`, with its `CONTROL_METHODS`) and `CLITestHelpers.build_cli(**keywords)`, the one way a spec builds a CLI: `Workspace::CLI.new` from the keywords given when one is the CLI's own (`lineage:`, a command, ...), plus the `Common`, `Names`, `Launcher` and `families:` `build_cli` would make from them (`.cli_parts`; `lineage:`, `workflow_command:`, `workflow_project:` the agent family's commands, `AGENT_FAMILY_KEYWORDS`, the agent-run family's, `AGENT_RUN_FAMILY_KEYWORDS`, the pipeline family's `clock:`, `PIPELINE_FAMILY_KEYWORDS`, and the plan and spine family's, `PLAN_SPINE_FAMILY_KEYWORDS`, with `status_scope:` (shared with `CLI::Workflow`), go to those parts; one `AgentMessageClient` for the agent-run and pipeline families is built unless `agent_client:` is given), else `Workspace.build_cli`, forwarding its named overrides (`osascript:`, `ui_osascript:`, `workflow_source_runner:`, `tmux:`, ...); the two mixed is an `ArgumentError`

- `lib/workspace/help_json.rb` — `--help --json`: decides whether a command line truly asks for a help page in JSON, and turns the page text the command prints into one document, so the JSON and the text are the same words and cannot drift.
