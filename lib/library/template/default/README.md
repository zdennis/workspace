# default

The built-in tmuxinator template set. `project.yml` is the layout of a standard project (banner, agent and shell panes) and `worktree.yml` the one for a git worktree, rooted in the worktree directory. Select it with `tmuxinator.template`, or copy it with `workspace template new NAME`.
